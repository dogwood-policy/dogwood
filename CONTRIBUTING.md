# Contributing to Dogwood

Thank you for your interest in Dogwood.

**This repository is a published, read-only mirror.** Development happens in an
internal Amazon repository, and changes are mirrored out here on demand. At this
time we are **not accepting external contributions** — pull requests will not be
merged, and we do not use GitHub issues for tracking. This may change in the
future; watch this file for updates.

## Reporting bugs

Because we are not using GitHub issues yet, please do not open issues for bug
reports or feature requests. If you have found a **security** vulnerability, do
**not** open a public issue — follow the process in [SECURITY.md](SECURITY.md)
instead.

## Licensing

Any contribution that is accepted in the future will be licensed under the

notice.

## Code of Conduct

This project has adopted a [Code of Conduct](CODE_OF_CONDUCT.md). Please read it
before interacting with the project.
